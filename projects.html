Systems / OS · Aug 2025 – Nov 2025

Building GemOS

CS330 — Operating Systems, IIT Kanpur

A kernel built from scratch: custom memory management, scheduling, fault handling, and multithreading.

  • Built a custom memory allocator (malloc/free) using mmap() and implemented mremap() syscall for efficient memory remapping.
  • Implemented kernel fault handling for divide-by-zero faults with instruction skip, function skip, and user redirection.
  • Round-robin CPU scheduling with multi-level page table walks for mapping inspection.
  • Multithreading via clone/exit and semaphore-based synchronisation with spinlocks and wait queues.

Cryptography / Algorithms · Jan 2025 – Apr 2025

Primality Testing & RSA Cryptosystem

CS648 — Randomized Algorithms, IIT Kanpur

Re-invented Miller-Rabin and built a full RSA pipeline from first principles.

  • Miller-Rabin primality test via Fermat's Theorem — O(log³n) time for primality validation.
  • Deterministic tests for small inputs (Trial Division, Sieve of Eratosthenes); probabilistic tests for large inputs.
  • Full RSA pipeline: random prime generation, key generation using Euler's totient + Extended Euclidean, encryption/decryption using fast modular exponentiation.

Hardware / Cryptography · Apr 2025

Hardware Implementation of Elliptic Curve Cryptography

CS220 — Computer Organisation, IIT Kanpur

Verilog HDL implementation of a Curve-25519 elliptic curve scalar multiplier.

  • Designed hardware architecture for a Curve-25519 elliptic curve scalar multiplier in Verilog HDL.
  • Built a finite field multiplier leveraging modular reduction techniques applicable to Solinas primes.
  • FSM architecture for control flow over the scalar multiplication pipeline.

Machine Learning / Research · May 2024 – Jun 2024

PINN Application in Wave Simulation

SURGE Project, IIT Kanpur — under Dr. Subhajit Roy

Physics-Informed Neural Networks applied to the 1D heat equation.
