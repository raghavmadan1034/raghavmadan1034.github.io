Writing CSS That Scales

June 28, 2026 · Raghav

Most CSS problems are naming and consistency problems. A small token layer defined with custom properties solves both without any tooling.

Define tokens once

:root {
  --bg: #ffffff;
  --text: #1f2328;
  --accent: #0969da;
  --radius: 10px;
}

Every component then references the token instead of a literal value. Theming becomes a matter of overriding the same names under a selector. 

[data-theme="dark"] {
  --bg: #0d1117;
  --text: #e6edf3;
}

Keep selectors flat

One class per component, modifiers as extra classes, and almost no nesting. Deep descendant selectors are what makes stylesheets impossible to delete from later.

If you cannot delete a rule confidently, the stylesheet is already too coupled.
