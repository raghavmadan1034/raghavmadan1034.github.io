Getting Started with Static Sites

July 12, 2026 · Raghav

A static site is just files: HTML, CSS, JavaScript and images served exactly as they are stored. There is no application server rendering pages per request, which removes an entire class of failure modes.

Why it still works

  • Speed. The server does no work beyond reading a file.
  • Cost. Free tiers on GitHub Pages, Netlify or Azure Static Web Apps are generous.
  • Safety. No database and no server runtime means a much smaller attack surface.
Start with files. Add a build step only when repetition actually hurts.

A minimal structure

index.html
about.html
posts/
assets/css/style.css
assets/js/main.js

When copy-pasting the header into every page starts to sting, move to a static site generator. Until then, the plain approach keeps the whole project readable in an afternoon.
