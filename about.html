About

BlogSite is a sample static website: plain HTML, CSS and JavaScript with no build step and no dependencies. Open index.html in a browser and it works.

What is inside

  • index.html — post listing with live search
  • about.html — this page
  • posts/ — individual article pages
  • assets/css/style.css — design tokens, layout and dark theme
  • assets/js/posts.js — post metadata used by the listing
  • assets/js/main.js — rendering, search and theme toggle

Adding a post

Copy an existing file in posts/, edit the content, then add a matching entry to the POSTS array in assets/js/posts.js.
